# ADR-0008: Lease machine ported verbatim

**Status:** Accepted (2026-08-22) — not open for redesign as part of this port

## Context

The main-turn lease state machine exists to solve one specific
correctness problem: a client that disconnects mid-turn must never cause
that turn to be committed to conversation state as if the client had seen
it complete. Without this, an aborted request could silently leave a
"completed" turn in history that the user never actually witnessed
finishing — a state the user has no way to notice or correct after the
fact.

This is a correctness property with real consequences (corrupted-looking
conversation history), not a performance optimization. A language port is
exactly the kind of change where subtly altering state-machine semantics
while translating syntax is easy to do by accident.

## Decision

The lease state machine is ported verbatim: same states, same transition
table, same `AllowsCommit()` gating logic.

```
in_flight → completed_committed
          → client_aborted_before_first_event
          → client_aborted_after_visible_output
          → backend_failed_before_commit
          → commit_suppressed_after_abort
```

Only `in_flight` allows a commit. The per-session mutex registry that
serializes lease operations per session is ported the same way. This
combination is called out explicitly in `ARCHITECTURE_v2.md` as a CORE
FEATURE not subject to the general license to reshape things during
porting.

`GAPS.md` G2 (leases are memory-only, lost on process restart) is a
separate, explicitly *open* decision — see [ADR-0010](ADR-0010.md) — and
does not change the state machine itself; it's about whether lease state
survives a crash, not what the states mean.

## Consequences

- Anyone touching `core/domain/transport/lease.go` or its implementation
  should treat a proposed behavior change here as a correctness review,
  not a refactor — get a second reviewer who understands the original
  aborted-client problem before changing transition logic.
- The port's job here was translation, not improvement. If a real bug is
  found in the lease machine's logic itself (as opposed to its
  persistence, which is tracked separately), that's a bug report against
  the *design*, to be fixed deliberately and on both implementations
  during the coexistence period, not folded silently into "the Go
  version."

## Alternatives considered

- **Simplify the state machine during the port** — rejected outright; the
  states encode specific abort/failure scenarios the Rust implementation
  was built to handle, and collapsing them risks losing distinctions that
  actually matter for correctness.
